# m1plus-mod

**M1+ Music** brings a modern music-player interface to the **Shanling M1 Plus**, built on
official V2.1 firmware.

[Install](docs/install.md) · [User guide](docs/guide.md) · [UI preview](docs/ui.md) · [Development](docs/workflow.md)

## Features

- **Browse:** Cover Flow, album grids/lists, Artists, an A–Z Songs list and Playlists.
- **Home:** Daily Mix, Recently Played and a floating mini player.
- **Now Playing:** cover-colour backgrounds, rounded artwork and remaining time.
- **Extras:** album/folder shuffle, local podcasts, a virtual iPod and Cassette Mode.
- **Appearance:** a translucent lock screen, minimal theme, Lucide icons and Inter + Source Han Sans fonts.
- **Customize:** choose menu items, startup behaviour, Cover Flow orientation and album order.
- **Languages:** the added UI follows the player's language setting, with 13 translations.

Stock settings and Tidal remain accessible. See the [user guide](docs/guide.md) for controls and options.

## Install and update

Install a verified `update.bin` from the TF card using the player's System Update menu.
Follow the [installation guide](docs/install.md) for preparation, updates and restoring stock.
